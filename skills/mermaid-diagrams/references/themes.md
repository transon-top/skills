# beautiful-mermaid 主题(15 款)

`render-diagrams.mjs` 的 `[theme]` 参数取值,默认 `github-light`。

## 亮色

| 键 | 风格 |
| -- | ---- |
| `github-light` | GitHub 风,中性偏冷,默认推荐 |
| `zinc-light` | 中性灰,低调 |
| `nord-light` | 北欧冷蓝,清爽 |
| `tokyo-night-light` | 东京夜亮色变体,紫蓝点缀 |
| `catppuccin-latte` | Catppuccin 拿铁,柔和低饱和 |
| `solarized-light` | Solarized 米黄底,护眼 |

## 暗色

| 键 | 风格 |
| -- | ---- |
| `github-dark` | GitHub 风暗色,与技术文档同源 |
| `zinc-dark` | 中性灰暗色 |
| `nord` | 北欧冷蓝暗色 |
| `tokyo-night` | 东京夜,紫蓝霓虹 |
| `tokyo-night-storm` | 东京夜暴风雨,更深对比 |
| `catppuccin-mocha` | Catppuccin 摩卡,柔和低饱和 |
| `dracula` | 高饱和紫黑暗色 |
| `solarized-dark` | Solarized 深青暗色 |
| `one-dark` | Atom One Dark,经典编辑器配色 |

## 选型

- 一个文档 / 项目**一款主题到底**,风格统一优先于单张好看
- 亮色文档配亮色主题,深色站点配暗色主题;不确定用 `github-light`
