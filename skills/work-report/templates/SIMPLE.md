# simple 模式模板

大类映射、大类排序、聚合规则见 SKILL.md 第 3 节，本文件只定义条目写法与输出骨架。

## 条目写法

- 每条 `功能域: 一句话描述`，从项目视角阐述功能价值，不涉及代码细节
- 同一功能域合并相近条目
- 只输出有提交的大类，无提交的大类不出现

## 输出格式

```markdown
# 工作汇报 (<start-date> ~ <end-date>)

**分支**: <branch> | **提交数**: <count> | **口径**: 交付日

## <大类一>

- <功能域>: <一句话描述>
- ...

## <大类二>

- ...
```
