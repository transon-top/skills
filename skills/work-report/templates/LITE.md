# lite 模式模板

交付日归属见 SKILL.md 第 2 节，领域聚类与确认见第 3.2 节；本文件只定义报告骨架。面向快速浏览：领域分组、业务点合并，不叙述。

## 章节

- 章节标题 = 领域语义名，由第 3.2 节语义聚类得出并经确认点校正
- 章节按提交量降序，确认点可调；只输出有提交的领域
- 无大类章节；type 信息降级为条目标签

## 条目写法

- 每条 = 一个业务点的合并概括：同领域同目标的 commits 合并成一条，压缩措辞、去重复，保留业务含义，不逐字抄 subject
- 不逐 commit 罗列，不做价值叙述，不展开背景，不用完整句子
- type 标签可选标注（`新增`/`修复`/`重构`/`文档`…）
- 条目不标日期，组内按最早交付日时间序

## 输出格式

```markdown
# 工作汇报 (<start-date> ~ <end-date>)

**分支**: <branch> | **提交数**: <count> | **口径**: 交付日

## <领域>

- <业务点概括>
- ...

## <领域二>

- ...
```
