# Anatomy Course

## 目标

输入一个代码仓库，产出面向有开发经验的开发者的图解课程：先给仓库整体全景图，再逐节点展开讲解代码结构、模块关系、各层作用。目的是让学员建立该仓库的**宏观思维模型**——拿到任何新仓库都能按这套地图去读。

**事实依据**：代码是唯一事实来源。仓库文档（`docs/`、`AGENTS.md` 等）只做四件事——核对语义、防止理解偏差、延伸阅读、来源标注。文档与代码冲突时**以代码为准**，图必须能独立从代码建出。

教学法参考 `/teach`：当前目录即课程 workspace（有状态），`MISSION.md` 定动机，`lessons/000N-*.html` 每课一个自包含 HTML，每课只给一个小胜利，检索练习（quiz）+ 迁移任务，命中学员的"最近发展区"。

## 核心边界

- 教的是"仓库怎么读"的思维模型，**不教编程基本功**；学员是有经验开发者
- 课程是教学产品，不是笔记：结构完整、风格一致、可交付
- **代码优先建图**：每张图的每个节点都必须可追溯到一个代码实体（文件 / 目录 / 符号 / 事件名），图面用代码原名；仓库文档不做图源，只做语义核对与延伸阅读
- 不碰仓库内已有的个人学习痕迹（如 clone 里未跟踪的 `lessons/`、`MISSION.md`）：课程产物独立，与自学笔记并存

## 解剖方法论（7 步）

1. **全景**：仓库是什么、解决什么问题、规模体量（一张或一组子图）
2. **骨架**：文件树按职能映射——哪些目录 = 哪些子系统
3. **构建与入口**：从启动/构建脚本走到第一个运行的代码
4. **核心子系统逐个拆**：每子系统一课（职责 + 内部结构 + 一张局部图）。⚠️ 一课只拆一个子系统，别贪
5. **协作网**：模块间数据流/调用链（时序图、class 图），补全景图看不到的"关系"
6. **支撑层**：测试 / CI / 发布 / 文档等"作用但不显眼"的部分
7. **收尾**：把课程的组织方式迁移到学员自己仓库的对照检查点

## 生成流程（交互式）

1. **定 MISSION**：当前目录无 `MISSION.md` 时，先访谈定下（为什么学 / 成功长什么样 / 约束）。有则直接读。
2. **产大纲 + 展开树**：按 7 步推出课程大纲——每课标题、要点、图清单；**同时产出展开树**：每课标注"本课总览锚到哪一节点、本课图序列（第一张是本课总览，其余逐张展开）"。**交给用户确认/修改后**才进入逐课生成。大纲确认 = 树确认。
3. **逐课生成**：每课一个 `lessons/000N-slug.html`，一节课过目后继续下一节。课程 8~12 课，每课 10~15 分钟；图多则自然拆课，不设每课图数硬限。
4. **收尾**：生成目录索引页（各课互相链接）+ `reference/*.html` 速查材料（术语表 / 图集 / 命令速查）。

## 每课结构（10~15 分钟）

- **教学参数**：一主题一图或一组子图（图少而清，规则见「图解」）；2~3 道 quiz（选项字数对齐，防暗示答案）；末尾 1 个"迁移任务"（学员在课程仓库里动手验证）
- **展开位置条**：每课顶部一条"本课在树的哪里"——`仓库全景 → AgentLoop → turn/step` 式路径条；块内段点击跳到本课 HTML 内对应图的锚点（`#anchor`），跨课段链接到对应课 HTML
- **导览式正文**：逐个节点带读——"这是 X，在 `路径`，做 Z"，每段紧跟"👉 去看代码哪里"；关键处内嵌 3~5 行真实代码片段，其余只给路径指路，不照着文档转述
- **自包含 HTML**：不依赖外部网络（本地可直开）。图示用 SVG 内嵌；**样式用共享 `assets/lesson-styles.css`**——模板 `<link rel="stylesheet" href="../assets/lesson-styles.css">` 引入，课内不再内联 `<style>`，样式一处定义、全课程复用（关注点分离：结构在模板，样式在 CSS，行为在 quiz 内联 JS）；quiz 用一小段内联 JS。浏览器直接打开即可用，可打印
- **检索练习**：quiz 面向"回忆"而非"认出"，feedback 越紧越好
- **quiz 反馈预设**：答对 = 绿色（`.fb.ok` 背景 `#d7edd9`、文字 `#2d6a3f`、边框 `#9cd09e`，按钮边框绿 `#2d6a3f`）；答错 = 暖黄（`.fb.no` 背景 `#f8ece7`、文字 `#8a4c33`，按钮边框红 `#bf616a`）。全课程一致

## 图解

- 默认 **beautiful-mermaid**（`renderMermaidSVG`）直出 SVG 字符串内嵌 HTML，零 CDN、离线可用；用统一主题（`THEMES` 15 款内置主题之一），全课程风格一致
- 支持的 6 种类型足够：flowchart（架构分层 / 依赖）、class（模块关系）、sequence（调用链）、state、ER（实体关系）、xychart
- 需要 timeline / gantt / mindmap / C4 类型时：封装改为 **mermaid-cli**（headless 预渲染 SVG），封装处只改一处
- **节点上限 6**：每张图最多 6 个主要元素（flowchart 计方框，sequence 计参与者，class 计类，ER 计实体，state 计状态）。超限的主题拆成**图组**：按读数顺序拆成 2~3 张姊妹子图，图名以 `-1`/`-2` 后缀编号，相邻排放同一处；大图渲染慢、视线扫不到，拆成小图逐张读，观感更好
- **严格展开树**：全课程共一棵树。第 0 层 = 仓库总览（L01，≤6 节点，按真实运行时链路建）；之后的每张图**恰好是前面某张图某个节点的展开**——展开图以被展开节点为入口（标题 + 首节点标注同词同名、"从哪进"唯一），图内节点是该节点的分解细节。展开顺序：按 7 步读取顺序，优先展开"脊柱"节点（被最多依赖 / 最先执行）；两者冲突时以实际代码分析出的主线优先
- **图组结构**：多张图时第 1 图是**总览**（画整体心智模型），其余子图按读数顺序拆解；每张子图的第一个节点必须在总览图中找得到（同一概念作锚点，同词，读者知道"从哪进"）
- **节点命名**：代码原名 + 小字职能注解（如 `AgentLoop · 主循环`），省略号禁用——beautiful-mermaid 不截断长文本，标签原样撑大节点、挤爆布局。节点只放一个**完整短语**；短语放不下完整文案时，节点写"概括词 + 序号"，图下方放**注解列表**，按序号展开全文（列表中 1. 2. 3. 对应节点标签里的序号）
- **锚点**：图面只放节点名；图下注解列表按序号放「节点名 — 锚点（仓库相对路径:符号）— 一句话说明」，与"长文案注解列表"合并。每个节点必须能追溯一个代码实体（文件 / 目录 / 符号 / 事件名）
- **来源 / 依据**：图下并列「来源：文档（如 `docs/architecture.md`，可无）+ 依据：代码锚点（必有）」。依据是代码事实，来源是文档出处，两者分开写
- **概念豁免**：仓库外概念（ACP 协议、CI 工具等）允许每课 ≤1 个概念段落，不上图；只有 Cordis 语法课（L02）允许"概念节点"的图，且该课不进展开树，作为**语法附录**放在 L01 之后——语法课先学语言，再进读码地图
- 每张"全景图"可附带 ASCII 渲染版（纯文本/终端阅读降级）

## 工具链(技能自带)

图形与课程组装脚本在 `tools/`(与 skills 一起发布),首次使用在本目录执行:

```sh
cd tools && npm install        # 安装 beautiful-mermaid
node tools/render-diagrams.mjs <图源目录> <SVG输出目录> [theme]   # .mmd → .svg
node tools/build-lesson.mjs <模板目录> <SVG目录> <成品目录>        # .html.tpl → .html(内嵌 SVG)
```

课程 workspace 只保留**内容与成品**;图源(.mmd)、模板(.html.tpl)、工具链均不混入成品目录。

## 完成校验

每课：浏览器直接打开图渲染完整 ✅ quiz 可答、页面无死链 ✅ 索引页链接全 ✅ 每课 `<link rel="stylesheet" href="../assets/lesson-styles.css">` 引入、无内联 `<style>` ✅ 每图主要元素 ≤6、超限主题已拆成图组 ✅ 图组首图为总览、子图节点锚点可寻 ✅ 节点无省略号、长文案已走序号注解 ✅ 展开位置条存在且跨课链接正确 ✅

**代码依据校验**（每图）：① 每个节点可追溯一个代码实体（文件 / 符号 / 事件名），依据列出代码路径；② 每张图（除第 0 层仓库总览与语法附录 L02）的每个节点，在上一层图找得到同名节点（同词同名、一一对应）；③ 正文"依据"含代码路径或短代码片段；④ 图下「依据」必须存在，「来源」可无。可用 `node tools/verify-anchors.mjs <图源目录> <仓库根> [图名...]` 自动核对节点名 ↔ 代码符号。跑不通就重画，不放过。概念段落（仓库外概念）每课 ≤1 且不上图。
